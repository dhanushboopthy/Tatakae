# Story reference pack

The app ships **without** any franchise content. Your personal pack lives in `*.local.json` (git-ignored) and is imported via Settings → Story.

Rules for every entry:
- `lesson` is **your own paraphrase**, max 160 characters. Never a verbatim quote or line of dialogue.
- No images, logos, audio, screenshots.
- `moment` is one of: p1_done, minimum_done, comeback, stuck_fear, stuck_inertia, weekly_review, cycle_start, rest_day.
